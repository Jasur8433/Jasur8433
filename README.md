# Feedback portal (RU / UZ / KK)

Обновлено по требованиям:
- Оценка полностью анонимная (без ФИО, телефона и комментариев).
- Голоса и рейтинг хранятся в отдельной базе данных SQLite (`feedback.db`), а не в `localStorage`.
- Доступно удаление нежелательных/спам голосов через админ-панель (кнопка `×` у каждой записи).
- При нажатии/сканировании QR открывается страница анонимной оценки конкретного подразделения (`#rate/<department>`).
- Интерфейс адаптирован под ПК и телефон.

## Запуск
```bash
python3 server.py
```
Открыть: `http://localhost:3000`

## Админ вход
- `admin`
- `admin123`

## Управление спам-голосами
- Удаление одной записи: в админ-панели нажмите `×` напротив нужного голоса.
- Полная очистка базы голосов (при необходимости):
```bash
curl -X DELETE http://localhost:3000/api/votes
```
