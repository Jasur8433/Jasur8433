# Feedback portal (RU / UZ / KK)

Обновлено по требованиям:
- Оценка полностью анонимная (без ФИО, телефона и комментариев).
- Голоса хранятся локально в отдельном файле `feedback-votes.json` (через браузер).
- Не требуется запуск Python/SQLite/серверной базы.
- В админ-панели можно удалять нежелательные/спам-голоса.

## Запуск
Просто откройте `index.html` в браузере.

## Как включить хранение в отдельном файле
1. Откройте `#admin` и войдите как админ.
2. Нажмите кнопку **«Подключить файл»**.
3. Выберите/создайте файл `feedback-votes.json`.
4. После этого новые голоса будут сохраняться в этот файл (анонимно).

> Если браузер не поддерживает File System Access API, используется временное хранилище браузера (`localStorage`).
