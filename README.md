# Feedback portal (RU / UZ / KK)

Обновлено по требованиям:
- Убрана форма «оставить обращение».
- Оценка полностью анонимная (без ФИО, телефона и комментариев).
- При нажатии/сканировании QR открывается страница анонимной оценки конкретного подразделения (`#rate/<department>`).
- Интерфейс адаптирован под ПК и телефон.
- Есть админ-панель для просмотра агрегированной статистики и ленты анонимных оценок.

## Запуск
```bash
python3 -m http.server 3000
```
Открыть: `http://localhost:3000`
